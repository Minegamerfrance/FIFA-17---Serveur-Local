Correction codec TDF / test du Ping
------------------------------------
- Cause concrète trouvée dans `TdfReader/TdfWriter.read/writeCompact` :
  l'ancien codec utilisait 7 bits dans le premier octet d'un entier TDF.
  Blaze TDF en utilise 6, puis 7 bits pour les octets suivants.
- Tout entier >=64 était donc mal encodé, notamment `PingResponse.STIM`.
- Codec corrigé et validé sur neuf vecteurs (`npm run test:tdf`).
- `STIM` envoie maintenant l'heure Unix en secondes dans un uint32 natif.
- Test isolé : `npm run start:ping-codec-test` (baseline PreAuth,
  `PING_SWALLOW=0`).
- Hooks froids ajoutés :
  `PING_CALLBACK_LEAN` @ `0x6e1d290` et
  `PING_LISTENER_LEAN` @ `0x6fcf789`.
- Succès attendu : `PING_CALLBACK_LEAN ... err=0x0 ... STIM=...`, puis au
  moins un `PING_LISTENER_LEAN`. Observer ensuite Auth/Login/Origin.

Résultat live du Resolver / A-B instrumentation
------------------------------------------------

Crash natif exact / correctif sentinelle opt-in
-----------------------------------------------
- Exception prouvée :
  `RVA 0x61638b5: mov rax,[rcx-8]`, avec `rcx=1`, lecture fautive
  `0xfffffffffffffff9`.
- Le helper `RVA 0x61638b0` traite déjà `rcx=0` comme une valeur vide et
  retourne `-1`. La valeur `1` est une sentinelle invalide pour son
  déréférencement.
- `PIPE_CRASH_FIX=1` est un correctif expérimental strictement borné :
  uniquement pour cette access violation exacte, après PréAuth réussi et
  avec `rcx==1`, le gestionnaire reprend à la branche native null-return
  `RVA 0x61638ea` puis retourne `true`.
- Aucun octet de FIFA17.exe n'est modifié. La valeur par défaut reste
  `PIPE_CRASH_FIX=0`.
- Le log ajoute aussi `CRASH_BACKTRACE`. Succès du correctif :
  `CRASH_SENTINEL_FIX applied`, puis absence de fermeture immédiate et,
  idéalement, nouvelles requêtes Auth/Nucleus/FUT.
